# Glossary

| Term | Meaning in this repository |
| --- | --- |
| Agent | The configured system that chooses or executes actions to pursue a task |
| Task | A problem instance with inputs, constraints, and success criteria |
| Suite | A versioned collection of evaluation tasks |
| Trial | One attempt by an agent to complete one task |
| Run | An execution of an evaluation configuration over a suite |
| Harness | Code that presents tasks, invokes the agent, and records observations |
| Grader | A rule or process that judges an observed output or state |
| Metric | A defined measurement computed from observations or judgments |
| Trace | A record of intermediate actions, tool calls, and observations |
| Baseline | A reference system or configuration used for comparison |
| Held-out set | Tasks reserved for evaluation rather than development |
| Contamination | Prior exposure to evaluation tasks or answers that undermines the intended comparison |
