# Documentation Index

Follow the topics in order for a first evaluation, or jump to the area you need.

1. [Foundations](foundations/README.md): define what is being evaluated.
2. [Evaluation Design](evaluation-design/README.md): select tasks and control the experiment.
3. [Metrics](metrics/README.md): choose what to measure and how to aggregate it.
4. [Benchmarks](benchmarks/README.md): assess whether an existing suite fits your needs.
5. [Practical Guides](practical-guides/README.md): run and inspect a small evaluation.
6. [Case Studies](case-studies/README.md): document a reproducible experiment.

Use the [glossary](glossary.md) for terminology and the [templates](../templates/README.md) to start writing.
