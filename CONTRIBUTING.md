# Contributing

Open an issue for a proposed topic or send a focused pull request. Use English for repository documentation so the library remains accessible to a broad audience.

## Writing guidelines

- Put the main question and practical takeaway first.
- Define the task, environment, agent, and grader when discussing an experiment.
- Link primary sources for external factual claims; record the version and access date when behavior may change.
- Distinguish a source's claims from your interpretation and your own measurements.
- Include limitations, failure cases, and reproduction instructions for experimental results.
- Do not commit credentials, private traces, personal data, or datasets without permission to redistribute them.

## Where to put changes

Use the [topic index](docs/README.md) to choose a location. Put new benchmark reviews in `docs/benchmarks/` and experiment write-ups in `docs/case-studies/`. Start from a [template](templates/README.md), give the file a descriptive kebab-case name, and add a link to the relevant index.

## Before submitting

Check that relative links resolve, terminology matches the [glossary](docs/glossary.md), and any code example includes its setup and expected behavior. No documentation build system is required.
