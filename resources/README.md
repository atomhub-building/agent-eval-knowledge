# Resources

This index is ready for curated papers, datasets, benchmarks, and tools. No external resources have been reviewed yet.

For each addition, include:

- Title and primary source URL.
- Authors or maintaining organization.
- Publication date or release version, plus the date you checked it.
- A short description of the evaluation problem it addresses.
- Why it is useful and what its limitations are.
- A link to a detailed note in `docs/` when available.

Prefer a small, explained collection over an unannotated list of links. Confirm redistribution terms before copying external material into this repository.
